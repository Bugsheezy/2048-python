# 2048 Python

A desktop implementation of the classic 2048 puzzle game, built with Python and Tkinter.

This project was created as a practical introduction to Python programming, game logic, graphical user interfaces, debugging, and Git version control.

![2048 gameplay](screenshots/2048-game.png)

## Features

- Fully playable 4×4 2048 game
- Arrow-key controls
- Tile movement in all four directions
- Correct tile merging logic
- Dynamic score tracking
- Random tile generation
- 90% chance of spawning a 2 and 10% chance of spawning a 4
- New tiles only spawn after a successful move
- Game-over detection
- 2048 win detection
- New Game button
- Colour-coded tiles
- Graphical interface built with Tkinter

## Technologies Used

- Python 3
- Tkinter
- Git
- GitHub
- Visual Studio Code
